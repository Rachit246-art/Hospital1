# AURA Health & Research Sanctuary

An ultra-premium, luxury hospital and research sanctuary website built with pure HTML5, CSS3, and modern vanilla JavaScript.

## 🌟 Highlights & Features

- **Biophilic & Editorial Healthcare Aesthetics**: Warm ivory (`#FAF9F6`), deep forest green (`#102C24`), and champagne gold (`#C5A36A`) color palette.
- **Hero Carousel with Ken Burns Slow Zoom**: 3 automated luxury slides featuring sub-millimeter surgical accuracy, robotic navigation, and presidential recovery suites. Left-middle aligned typography with custom indicator progress bars and touch swipe support.
- **Floating Glassmorphic Instrument Panel**: Responsive floating dynamic island navbar with active state tracking, rapid consultation booking, and a mobile slide-in drawer navigation system.
- **Cinematic Inner Page Heroes**: Bespoke full-bleed atmospheric photography, glowing category badges, glassmorphic breadcrumb pills, and clinical metric trust ribbons across all 6 inner pages:
  - `about.html` — Our Approach & Founding Ethos (Heritage timeline, biophilic architecture, governing council)
  - `specialties.html` — Medical Specialties & Centers of Excellence (Filterable procedural showcases, clinical outcomes)
  - `facilities.html` — Biomedical Infrastructure (360 suite switcher, live environmental room gauges)
  - `doctors.html` — Specialist Directory (Live client-side search, department filter pills, 1-click consultation pre-fill)
  - `patient-care.html` — Concierge Care Experience (Bento grid, 4-step care pathway, recovery stories)
  - `contact.html` — Sanctuary Pavilion & Emergency Access (Live trauma status bar, HIPAA inquiry form, vector campus map)
- **Interactive Modals**:
  - Private Clinical Consultation Booking Modal with auto department pre-fill.
  - Immersive Virtual Walkthrough & 360 Room Tour Modal.
- **Full Mobile Responsiveness**: Seamless scaling across smartphones (320px–480px), tablets (768px–1024px), laptops, and large desktop screens. Zero external dependencies.

## 🛠️ Technology Stack

- **HTML5**: Semantic, accessible markup.
- **CSS3**: Custom design tokens, glassmorphism, responsive grid & flexbox layouts, keyframe animations.
- **Vanilla JavaScript**: Carousel engine, slide-in mobile drawer, smooth scroll reveals, live filtering & search, modal managers, animated counters.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve locally:

```bash
# Using Python
python -m http.server 3000

# Using Node.js
npx serve .
```

Open `http://localhost:3000` in your browser.
